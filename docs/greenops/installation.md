# Anubis-GreenOps Agent — Installation Guide

Anubis-GreenOps installs through the same unified installer as the rest
of the suite — see [`../installation.md`](../installation.md) for
prerequisites, quick install, manual install and troubleshooting.

To install only Anubis-GreenOps:

```bash
./install.sh --suite greenops
```

This installs `Anubis.GreenOps.md` plus the shared runtime package
(`references/`, `schemas/`, `examples/`) required at runtime, including
`references/sustainability.md`.
